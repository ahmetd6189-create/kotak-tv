# Team icon assets

Bundled from the ESPN team directory/logo URLs recorded in `src/native/team-directory.json` on 2026-10-29. Each entry retains the source logo URL, country, league and provider ID. PNG icons are stored as base64 in `team-icons.json` and decoded by the Expo config plugin without build-time network requests.

The default Kotak K icon is an original vector resource in `default-icon.xml`.
